# Xntrova — Authority Landing Page

A third, visually distinct Xntrova landing-page concept built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Highlights

- Responsive desktop/tablet/mobile layout
- Sticky navigation with mobile menu
- Hero growth-signal visual
- Capabilities/services section
- Outcome metrics dashboard
- 4-step approach
- Testimonial/brand statement
- FAQ accordion
- Contact lead form with validation and success state
- Semantic HTML and SEO metadata
- No Tailwind dependency

The form is frontend-only and can be connected to the company's backend or email provider.
